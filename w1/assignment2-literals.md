# Literals
```python
print(5 + 2 - 2)
# 5
print(5 / 2)
# 2.5
print(6 // 2) # // integer division
# 3
print(2. * 3)
# 6.0
print(2 < 4)
# True
print(2 >= 2)
# True
print("Hello"+"World")
# HelloWorld
print("bla" * 3)
# blablabla
print(2 * 3 ** 3)
# 54
print(5 * 25 // 13 + 100 / 2 % 13 // 2)
# 14
print(2 * 3 % 5)
# 1
print((2 % -4), (2 % 4), (2 ** 3 ** 2))
# 2 2 512
```
